boxOS client documentation

Protocol documentation for people and agents implementing boxOS clients.

Hosted client

import { BoxOSClient } from "https://api.boxos.org/client.js";

const box = new BoxOSClient("https://api.boxos.org");
const counter = box.proc<number>(`
  let count = +(ctx.load("count") || "0");
  count += 1;
  ctx.store("count", String(count));
  return count;
`);

const value = await counter.invoke("", { fuel: 30 });

The client creates an anonymous bearer identity, stores it in browser local storage when available, mines fuel when needed, computes procedure hashes, registers unknown procedures, and submits invocations. An identity can be exported with box.identity and passed to another client using { identity }.

Methods include balance, fund, ensureFuel, hash, register, invokeHash, run, proc, inspect, publish, and stats.

Endpoints

  • POST /challenge: issue a one-use proof-of-work challenge.
  • GET /balance: return the bearer identity's fuel balance.
  • POST /fuel: mint balance with proof of work.
  • POST /proc: register, invoke, or inspect a procedure.
  • POST /page: publish or renew one HTML page.
  • GET /stats: current prices and limits.
  • GET /client.js: browser ES module client.

The JSON API accepts cross-origin requests. Authenticated endpoints require Authorization: Bearer <43-character Base64URL identity>. The bearer value is a secret and should not be embedded in public source.

Fuel balances

To fund an identity, request a challenge and find a nonce for:

userId = SHA-256(bearerIdentity)
commitment = "fuel\n" + userId + "\n" + amount
input = JSON.stringify([challenge, amount, commitment, nonce])
difficulty = baseDifficultyBits + ceil(log2(amount))
SHA-256(UTF-8(input)) must have difficulty leading zero bits

Submit { amount, challenge, nonce } to POST /fuel. Challenges expire after 60 seconds and are consumed by one attempt.

Procedures

Procedure source is global and content-addressed by hexadecimal SHA-256. The same procedure hash has the same global persistent state for every user.

Register

{ "register": "return arg;" }

New source costs balance according to UTF-8 size and storage pressure. Registering already-known source is free.

Invoke

{ "invoke": "procedure hash", "arg": "string", "fuel": 30 }

The full requested fuel is reserved before execution. Successful transactions refund unused fuel. Exceptions, timeouts, worker failures, and optimistic conflicts receive no refund. A committed deletion earns balance after commit.

Inspect

{ "inspect": "procedure hash" }

Optimistic transactions

Workers execute concurrently against versioned keys and keep writes in a local overlay. At commit, the server verifies every key version read by the complete nested call tree. If any changed, no writes commit and the response contains { code: "conflict", retryable: true }. The server does not retry or refund conflicts.

Nested ctx.invoke(procedureHash, arg) calls share one read set, write set, fuel budget, and atomic commit.

Procedure language and capabilities

The language supports let, const, var, named functions, basic loops and conditionals, try/catch/finally, throwing expressions, literals, arrays, objects, calls, assignments, strict and coercing equality, fixed property access, and guarded numeric indexing.

Initial values are arg, ctx, frozen JSON, deterministic allowlisted Math without random, and callable String.

ctx provides store, load, delete, has, invoke, hash, validate, and schema helpers. Each procedure hash has its own global keyspace.

Content-addressed pages

box.publish(html) publishes one full-JavaScript HTML document of at most 32 KiB. Publication costs the current fixed page price and creates a seven-day renewable lease.

https://<16-character Base32 hash>.pages.boxos.org/

The hostname contains the first 80 SHA-256 bits. Collisions never overwrite content. Page hosts do not expose API routes.
