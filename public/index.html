BOXOS

A tiny backend made of transparent, permanent functions.

Submit restricted JavaScript once. BOXOS stores it under the SHA-256 hash of its exact source, gives it persistent state, and lets anyone inspect what it does.

Reducers update isolated state transactionally. Procedures make network requests and compose reducers. Immutable HTML pages receive short addresses and their own browser origins.

Execution and permanent storage consume explicit fuel—no deployment pipeline, framework stack, or hidden upgrade behavior.
